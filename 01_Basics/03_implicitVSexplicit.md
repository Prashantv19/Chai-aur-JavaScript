# Implicit vs Explicit — Programming Concept (JavaScript Focus)

## ✅ Core Meaning

- **Implicit = automatic behavior by the language**
- **Explicit = clearly written / manually specified by the programmer**

> Implicit → happens automatically  
> Explicit → you write the instruction yourself

---

## 🔹 Implicit (Automatic)

### Definition
Behavior that happens automatically without you directly specifying it.

---

### Example — Implicit Type Conversion (Coercion)

```js
console.log("5" + 2);

Output:"52"
```
### What happened:

- JavaScript automatically converted 2 → "2"

- String concatenation occurred

- Conversion was not written manually → implicit
